Own Your Stack publishes tested, copy-paste guides for freelancers and small businesses who want to replace monthly software bills with free, open-source apps on a server they control.

## How we test

Every setup file in our guides is run in Docker before the guide is published. Each guide says at the top what was tested, which versions, and on what date, and says plainly what wasn't tested. If we haven't run something, we don't claim it works.

The guides are written with AI assistance and checked by running them. Prices come from the providers' own pricing pages on the date shown.

## Corrections

Software changes fast. If a step no longer works or a price is out of date, [open an issue](https://github.com/whatnowhater-oss/own-your-stack/issues) and we'll fix it.
